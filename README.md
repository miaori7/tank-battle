# 坦克大战 Tank Battle

一个用纯 HTML / CSS / JavaScript 编写的经典《坦克大战》网页游戏，无需任何依赖，双击打开即可游玩。

## 玩法

- 控制你的坦克，消灭场上所有的敌人坦克
- **守住基地**（屏幕底部的鹰图标）——基地被摧毁即游戏结束
- 共 3 条命，每关 20 名敌人

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / `方向键` | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |
| `R` / `Enter` | 结束画面时重新开始 / 进入下一关 |

## 游戏元素

- **砖墙**：可被子弹摧毁
- **钢板**：只有满级火力（★ 强化 3 次）才能摧毁
- **水面**：阻挡坦克，但子弹可以穿过
- **草丛**：遮挡视线（可穿过）
- **基地**：必须守护的目标

### 敌人类型

| 类型 | 生命 | 速度 | 分数 |
| --- | --- | --- | --- |
| 基础 | 1 | 普通 | 100 |
| 快速 | 1 | 快 | 200 |
| 火力 | 2 | 中等 | 300（掉落道具） |
| 装甲 | 3 | 慢 | 400 |

### 道具

消灭「火力」敌人有机会掉落道具：

- **盾**：10 秒无敌
- **★**：提升火力（更快、更强的子弹）
- **炸**：消灭场上所有敌人
- **命**：增加一条生命
- **铲**：把基地周围的砖墙加固成钢板（15 秒）
- **冰**：冻结所有敌人 6 秒

## 运行

直接用浏览器打开 `index.html` 即可，或部署到任意静态托管服务（如 GitHub Pages）。
